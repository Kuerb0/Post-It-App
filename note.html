Anadir fechas: dias
Ctrl+B / I / U negrita, cursiva, subrayado
Ctrl+T tachado
Ctrl+Shift+H resaltar
Ctrl+Shift+1 título
Ctrl+Espacio quitar formato
- ␣  o  [] ␣ tarea con casilla
Ctrl+Enter crear tarea / marcarla
* ␣  /  1. ␣ viñetas / numerada
Ctrl+Shift+8 / 7 viñetas / numerada
/ menú de opciones (alarma, tarea, carpeta…): escribe para filtrar, ↑↓ y Intro. ⏰ Alarma: eliges fecha y hora (escribiéndola o con el selector) y a esa hora la nota salta aunque esté cerrada. Clic en la etiqueta para cambiarla o quitarla
Ctrl+Shift+O ordenar las carpetas por la fecha que llevan dentro: arriba la que llega antes desde hoy (se repite cada año); sin fecha, abajo. Se hace solo al abrir la nota, al salir de ella y al cambiar de día
Ctrl+Shift+F carpeta: la línea pasa a ser un título; con un clic esconde/muestra lo que tiene debajo hasta la siguiente carpeta
Tab / Shift+Tab sangría
Alt+↑ / Alt+↓ mover línea
Ctrl+N / Ctrl+W nueva / cerrar nota
Ctrl+L lanzador: todas las notas (abrir, principal, cuáles arrancan)
Ctrl+M minimizar (vuelve desde la barra de tareas o el icono de la bandeja)
Ctrl+Shift+C cambiar color
Ctrl+Shift+R linea periodica: se copia como tarea bajo las fechas (14/10, 15/10...) que haya mas abajo. Reglas: escribe en la linea cada 2 lunes, cada 3 dias, cada semana, cada 2 semanas, cada mes
Ctrl+Shift+D anadir varias fechas de golpe
Ctrl+Shift+K columnas: 2 / 3 / 4 / 5 / quitar
Ctrl+Shift+G translucida / opaca
Botón 📅 unir con el Calendario: sus eventos salen bajo cada fecha de la nota como tareas ☐ 📅 10:30 Reunión (clic en la casilla para tacharlos), y las líneas con hora que pongas bajo una fecha (22/10 → 18:30 Dentista) salen en él
Ctrl+Shift+P posición: normal / encima / debajo
